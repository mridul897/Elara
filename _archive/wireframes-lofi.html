Navigation pattern check — information-architecture.md Part 3

Checked against every frame above

Mobile (390px): top bar (menu · logo · search · bag) + full-height drawer for categories/account/wishlist. No bottom tab bar — product and checkout screens carry their own sticky primary action instead, so a tab bar never competes with Add to Bag/Buy Now or the checkout step buttons. Confirmed consistent across Homepage, PDP, Listing, Cart, Checkout.

Desktop (1024px+): full header nav, light dropdown under "Bags" (no mega-menu), breadcrumbs on Listing/PDP, cart as a right-side drawer, checkout header reduced to logo + "Continue shopping" link. Confirmed consistent.

Gap found: Quick View and the Size & Dimensions sheet are both overlays with no shared close/back convention documented yet — same ✕ pattern should be used for both; add this as an explicit rule before high-fi.
